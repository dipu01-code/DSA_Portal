# Demo video script (Person 3) — about 8 minutes

**Before recording:** PostgreSQL + Redis up, `npm run db:migrate && npm run db:seed`, API on :3000 (`REDIS_URL=redis://localhost:6379 npm run dev:server`), worker running, web on :5173 (`npm run dev -w web`), the installed **DSA Practice.app** (from the .dmg), the Android emulator with `app-release.apk` installed. Two browser windows side by side are handy. Use a fresh account (`demo_viva` / `green-lamp-42`). Turn on "show clicks" in the recorder.
